============================================================
GUÍA DE GENERACIÓN DE PROYECTO (VISUAL STUDIO + PREMAKE)
============================================================

1. REQUISITOS PREVIOS
---------------------
- Tener Visual Studio 2022 instalado (con soporte para C++).
- Tener el repositorio clonado con todas sus carpetas (assets, src, deps).

2. CONFIGURACIÓN DE PREMAKE (IMPORTANTE)
----------------------------------------
El ejecutable "premake5.exe" NO se incluye en el repositorio.
1. Descargar Premake 5 desde: https://premake.github.io/download/
   (Descargar la versión de Windows).
2. Descomprimir el archivo ZIP.
3. Copiar el archivo "premake5.exe" dentro de la carpeta "tools/" de este proyecto.

3. GENERAR LA SOLUCIÓN .SLN
---------------------------
1. Abrir una consola (CMD o PowerShell).
2. Navegar a la CARPETA RAÍZ del proyecto.
   (IMPORTANTE: Quedarse en la raíz, NO entrar en la carpeta tools).
3. Ejecutar el siguiente comando:
   tools\premake5.exe vs2022

4. COMPILAR Y EJECUTAR
----------------------
1. Ir a la carpeta "build/" que se acaba de crear.
2. Abrir el archivo "AItest.sln" con Visual Studio.
3. Seleccionar la configuración "Debug".
4. Compilar (Ctrl+Shift+B).
5. Ejecutar (F5).

NOTAS:
- El ejecutable final estará en: bin\Debug\AItest.exe
- Las DLLs necesarias se copiarán automáticamente.
