============================================================
GUÍA DE COMPILACIÓN POR CONSOLA (SCRIPTS .BAT)
============================================================

HERRAMIENTA NECESARIA
---------------------
- Utilizar siempre: "x64 Native Tools Command Prompt for Visual Studio".
- Ubicación de ejecución: Carpeta "tools/" del proyecto.

FLUJO PRINCIPAL (comp.bat)
--------------------------
El script "comp.bat" automatiza todo el proceso. Al ejecutarlo:

1. Pregunta: "¿Limpiar antes? [S/N]"
   - S: Ejecuta limpieza de archivos temporales y antiguos.
   - N: Mantiene los archivos anteriores (compilación más rápida).

2. Compilación:
   - Compila el código fuente usando MSVC.
   - Genera el ejecutable en "bin/AItest.exe".
   - Copia automáticamente las DLLs necesarias (SDL2) a la carpeta bin.

3. Pregunta: "¿Ejecutar AItest.exe ahora? [S/N]"
   - S: Inicia el juego inmediatamente.
   - N: Termina el proceso sin abrir el juego.

RESUMEN DE SCRIPTS DISPONIBLES
------------------------------
1. comp.bat (RECOMENDADO)
   - Contiene todo: Limpieza (opcional) -> Compilación -> Ejecución (opcional).

2. compile.bat
   - Únicamente compila el código y mueve las DLLs. No pregunta ni ejecuta.

3. clear.bat
   - Limpia archivos basura (.obj, .pdb, .ilk) de las carpetas bin, build y tools.
   - Usar "clear.bat all" para borrar también el ejecutable y las DLLs.

SOLUCIÓN DE PROBLEMAS
---------------------
- Si falla la compilación, verificar que la carpeta "deps/" contiene SDL2 y SDL2_image correctamente.
- Asegurarse de estar ejecutando los comandos desde la carpeta "tools/".
